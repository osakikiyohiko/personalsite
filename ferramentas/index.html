Firewall Multivendor Configurator

Monte uma VPN IPsec site-to-site entre dois sites: arraste um firewall para cada site, informe os IPs públicos e as LANs e clique em Deploy para gerar a configuração de cada lado — os fabricantes podem ser diferentes em cada ponta.

Arraste um firewall até o site (ou toque no firewall e depois no site). Os nomes das interfaces WAN e LAN são opcionais: se ficarem vazios, é usado o padrão do fabricante.
